# SO-101 チェス（実装予定）

SO-101 で実物のチェスを人と対局するための設計です。構成図にチェスの分岐を追加しました。
チェスの画面・認識・局面管理・エンジン接続・実機操作は、まだ実装していません。

## エンジンと共通構成

- チェスAIは公式の [Stockfish](https://github.com/official-stockfish/Stockfish) を採用し、UCIで接続する。
- 将棋AIは [やねうら王（YaneuraOu）](https://github.com/yaneurao/YaneuraOu) をUSIで呼ぶ。ゲームごとにプロトコルと局面表現を分ける。
- 撮影・四隅検出・座標較正・搬送・経路評価・実機制御・再観測は共通化する計画。
- 正本は [構成図JSON](../構成図/構成図.json)。表示・進捗更新は [構成図README](../構成図/README.md) に従う。

## チェス側で追加する機能

1. **盤と駒の実測・認識**：8×8のマス座標、駒の高さ・把持位置を測定し、白黒6種と空を判定する。
2. **局面・合法手**：FENと着手履歴を管理する。キャスリング権、アンパッサン、昇格、チェック、反復・引き分け・終局を扱う。ルール実装の候補はpython-chessで、採用版と対応範囲を実装時に確認する。
3. **Stockfish接続**：UCI初期化、FEN/着手履歴送信、応手の合法性照合、時間切れ・異常終了への対応を実装する。版・ビルド・評価ファイルを固定して記録する。
4. **駒の在庫管理**：捕獲駒の回収先、昇格用の交換駒、取り外したポーンの置き場を実測して管理する。
5. **操作計画**：通常移動・取りに加え、キャスリングの2駒移動、移動先以外の駒を取るアンパッサン、ポーンを交換する昇格を計画する。
6. **確認と復旧**：操作途中の状態を保存し、再観測で予定局面と一致してから着手を確定する。駒の二重回収を防ぐ。

## 実施順序と評価

- [ ] 8×8盤、全駒種、回収先、昇格用交換駒の寸法・座標・到達性を評価する。
- [ ] 局面管理とStockfishのUCI接続をソフトウェアで検証する。
- [ ] 全64マスと隣接駒を含む通常移動・取り・特殊操作をシミュレーションで評価する。
- [ ] 共通の関節制御・較正・停止の実機ゲートを通過後、単駒から実機評価を始める。
- [ ] 再観測、特殊操作、途中失敗からの復旧を含めて対局を評価する。

構成図のチェス要素はすべて「未実装・予定」です。既存チェスロボットの搬送処理を参照する方針と、本リポジトリでチェス対局が動くことは別に扱います。
