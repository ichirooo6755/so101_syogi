# 構成図の呼び出しプロンプト

> so101_syogi のタグ付き構成図を表示してください。構成図/呼び出しプロンプト.md を読み、同じコミットの正本JSONから最新の進捗色を反映してください。

1. 対象は `ichirooo6755/so101_syogi`。指定されたブランチやコミットを優先する。指定がなければ対象のローカルチェックアウトを使う。GitHubだけを参照する場合は、タグ付き構成を含む既定ブランチを使い、未反映なら `codex/chess-stockfish-yaneuraou` を使う。
2. 同じコミットの [構成図.json](構成図.json)、[図設定.json](図設定.json)、[タグ付き構成.json](タグ付き構成.json) を読む。表示順、パーツ名、タグはタグ付き構成から、進捗は `modules[].status` と `status_definitions[].style` から取得する。
3. ブラウザでの表示はリポジトリルートで `python "構成図/show.py" open` を実行する。Codex内ブラウザなど表示先が指定されていれば、生成したHTMLをその表示先で開く。ファイルを書かずに生成する場合は `python "構成図/show.py" show --format html` を使う。GitHub上では[全体README](../README.md)内のSVGか[タグ付きSVG](タグ付き構成図.svg)を開く。
4. チェス・囲碁・将棋を左から並べ、同じ段階を同じ高さに揃える。共通処理は3列をまたぎ、箱を矢印で結ぶ。操作後の一致・不一致を分岐させ、機械モデル・教示からの入力は破線で示す。凡例、進捗更新日、実機送信ゲートの状態を添える。
5. 表示だけの依頼では、進捗やタグの定義は読み取り専用として扱う。

編集を依頼されたら [AI作業手順.json](../docs/AI作業手順.json) に従い、プロンプトの **対象・段階・パーツ** の3タグを照合する。例は `#囲碁 #盤面認識 #駒石認識`。進捗変更の依頼がある場合は `set-status` で根拠を記録し、`check` で生成物との同期を確認する。
