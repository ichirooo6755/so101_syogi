# 囲碁（未着手）

SO-101 で囲碁をやるための置き場です。**実装はまだありません。**
将棋側（`../shogi/`）の盤認識・座標変換・搬送の枠組みを流用する想定で、設計メモだけ先に置きます。

## 将棋から流用できる見込みのもの

- 盤四隅の検出（ArUco マーカー）と、盤座標 → ロボット座標の変換の枠組み
  （考え方は [../docs/board-geometry.md](../docs/board-geometry.md)、将棋の実装は `../shogi/app/board_map.py`）
- 手首カメラ（XIAO ESP32S3 Sense、`../shogi/firmware/ShogiCamera/`）とマウント試作
- MuJoCo による到達・接触評価（`../shogi/simulation/` の全マス評価を 19×19 交点に差し替える）
- 上腕延長部品の比較試作（ただし囲碁盤の大きさ次第で結論は変わる）

## 囲碁で新規に必要なこと

1. **盤の位置関係**: 19 路盤の交点間隔・外形を実測し、交点座標の式を決める。
   19 路がアームの到達範囲に収まるか先に評価する（難しければ 9 路／13 路から）。
2. **石の把持**: 碁石（円盤状）をグリッパーでつまむ／置く動作。隣の石との干渉確認。
3. **碁笥との往復**: 石を取り出す場所、取った石（アゲハマ）の置き場の設計。
4. **局面管理**: 着手履歴、コウ、アゲハマ、地の計算に使うルールエンジン／AI の選定。
5. **認識**: 交点ごとの黒石・白石・空の判定。将棋の駒種分類とは別モデルになる。
