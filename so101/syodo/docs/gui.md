# 書道GUI

`書道GUI.command` をダブルクリックすると、ローカルの画面が開きます。8765番が使用中の場合は別の空きポートを使います。軌道計算には書道用Python、実機操作にはLeRobotの実機用Pythonが必要です。「接続 → 実行環境」で設定します。カメラの目印検出には書道用Pythonに `opencv-contrib-python-headless` が必要です（プロジェクトの任意依存 `camera`）。

## 準備と書字

1. 「準備」で筆の全長240 mm、穂42 mmを確認し、**取り付け位置から毛先まで**を実測して保存します。全長とは別の値です。
2. 紙の書字領域に長方形を決め、奥行きと幅を定規で測って入力します。四隅と中央、中央上、硯の墨池、硯の引く端、姿勢の基準を画面の図に従い手で記録します。腕を支えてトルクをOFFにしてから動かします。
3. 紙・硯の位置を計算し、接続中のサーボ較正を同期します。定規の寸法や四隅の並びが合わない場合は修正します。
4. 硯の自動動作を使う場合、墨池と引く端の両方を記録し、動作の回数、速さ、待ち時間を設定します。距離や角度は勝手に推定しません。
5. 筆圧の試験軌道を確認し、墨なしの空中リハーサルの後、別紙に試験線を描きます。上と下で良い線を選びます。良い線がなければ中止します。
6. 「書く」で1〜2文字と実寸を指定し、軌道を確認します。書字領域に入らない寸法は縮小せず拒否します。画面の見本は筆順と配置であり墨の仕上がりではありません。
7. まず空中で試し、周囲への接触と狙った位置を目視して結果欄に記録します。硯を自動で使う場合は硯の動きも別に試して確認します。動かした後は現在位置から軌道を作り直し、書きます。

腕に取り付けたカメラは映像を記録し、受信が失われた場合は現在位置で停止します。画像の変化から衝突を検知する機能はありません。停止は電源遮断ではありません。手で動かすときは腕を支えてからトルクをOFFにします。

## 腕に取り付けたカメラで紙と硯を検出

この機能は**紙の四隅、中央、硯の2枚の目印が1枚の写真に同時に見える場合**に使えます。筆先付近しか映らないカメラでの複数姿勢による探索は未対応です。視野は実機で確認してください。

1. 上記の手動の位置・高さの較正を先に完了します。カメラを使う設定にします。硯の引く端も記録してください。
2. 「カメラで紙と硯を見つける」から目印を印刷します。紙の記録した四隅に0（手前左）、1（手前右）、2（奥右）、3（奥左）、中央に6を、それぞれ**印の中心を実測点に合わせて**置きます。4と5は30 mm以上離し、硯と一体に動く板に固定します。全ての印の中心を紙面と同じ高さに揃えます。筆の通り道からは動作前に取り除けるようにしてください。
3. 筆を垂直に保ち、目印が全て映る姿勢で静止して「カメラの基準を記録」を押します。撮影前後に姿勢を読み、変化した場合は失敗します。四隅の画像と実測座標から平面を計算し、中央の独立した確認が5 mmを超えると止まります。
4. 紙や硯を移動したら、カメラを基準撮影時と同じ姿勢に戻し「紙と硯を検出」。目印の画像を確認して「検出位置を反映」を押します。座標と逆運動学を計算するだけで、腕は動きません。反映後は筆圧が失効し、位置によってはサーボ範囲の再同期も必要です。紙は前後左右に合わせた長方形にしてください。
5. 目印を筆の通り道から取り除き、筆圧の再較正、硯の動作確認、空中試験を行います。単眼画像は紙面や墨面の高さ、障害物、筆や固定具の衝突を測りません。印は紙面と同じ高さ、カメラの取り付けは固定、硯の印は硯と一体である必要があります。画面外や印の周囲のレンズ歪み、印の高さが違う場合の誤差は未評価です。

## ロードセルと学習

Mac、カメラ、ロードセルと追加予定のIMUの接続先は、[図入り配線ガイド](配線ガイド_IMUカメラロードセル.md)を参照してください。HX711の基板ごとに電源の配線が異なります。

筆側の単一ロードセルをESP32のHX711で取得します。`firmware/esp32-sense-mjpeg` をXIAO ESP32S3 Senseへ書き込み、配線してから「接続」で有効にします。ゼロ点、既知の重り、別の重りで換算を確認します。ファームウェアはXIAO ESP32S3 Sense用カメラ配線、HX711のDAT=GPIO1・CLK=GPIO2を前提にしています。別のESP32-S3基板ではカメラのピン配置を確認して変更が必要です。「接続 → ESP32-S3にプログラムを書き込む」で、XIAOのUSBポートを指定して書き込めます。既存のプログラムは置き換わります。標準設定では起動後に `syodo-cam-XXXX` というWi-Fiが現れ、パスワードは `syodo-cam`、URLは `http://192.168.4.1` です。ファームウェアのビルドは実機書き込み・配線確認を意味しません。

画面に出るのはセンサの**計測軸方向の力**であり、重力や腕の動きも含みます。紙に垂直な筆圧そのものとは限りません。較正済みの場合、動作中に関節・力の時刻付きログを保存し、受信断や設定上限で停止します。バイラテラル中の教示も保存できます。人が実物を「良い／やり直し」と評価して「学習用データを書き出す」と、時刻の不確かさを考慮し関節と荷重を対応付けます。書き出しだけではモデルは学習されず、実機の上達も保証されません。

## 保存先と検証範囲

- `data/hardware/gui/settings.json` と `desk.json`: GUI専用の設定と較正。元の `data/hardware/desk.json` は保持します。
- `data/hardware/gui/camera-calibration.json`: 撮影姿勢と画像・平面の対応。机の較正が変わったら取り直します。
- `runs/gui/`: 経路、ログ、実物の評価、学習用データ。

カメラ・ESP32・ロードセル・腕の接続、取り付けた筆の実機到達性、衝突、実際の書字品質は現物での検証が必要です。
