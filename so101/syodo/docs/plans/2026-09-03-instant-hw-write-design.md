# タイプした文字を即書く `hw-write`

`./scripts/hw-write 文字`のように、コマンド直後へ指定した1〜2文字を現在のdeskと上下別筆圧から毎回traceし、既存の`play`で実書する。古いtraceは再利用しない。

既定は速度1.5、stride 1、開始待機0秒、接近6秒。空中リハーサルは行わず、自動硯2往復と毛先整え後に本書きする。trace、荷重・電流CSV、判定JSONは同じtimestampのrunへ保存する。カメラなど追加の`play`オプションは文字の後へ渡せる。

入力なし、3文字以上、KanjiVGで軌道生成できない文字はFollower接続前に停止する。既存の関節端、IK誤差、筆の傾き、荷重、通信、カメラ異常時の退避は変更しない。`文字・学習・菅原`を実機品質の合格対象とし、ほかのKanjiVG収録文字は汎用対応とする。
