# 固定45°斜筆・Z筆圧による回復方針

## 判断

- サーボ電気角45°は現行CAD上の「筆直立ホーム」であり、物理的な斜筆45°とは別物。
- 新方式では3画以下の単純字にある露出横画だけ、接地前に筆軸を物理45°へ構え、接地中は傾斜サーボを固定する。右上85 mm枠は固定姿勢で床接触するため既存制御へ安全フォールバックする。接地後の紙に対する実角度は追わず、筆先XYZを優先する。複雑字・接合画・縦画・払いも既存の低角度制御を維持し、固定45°の展開は別ゲートにする。
- 起筆・送筆・収筆の形は角度変更ではなく、筆先XYZと実圧フィードバック、とくにZの押し込み・抜きで作る。
- 30→8°を送筆中に動かす現行方式は採用しない。全60ケースで完筆したが、beauty 71.56、端点の直立比 +5.16、消失布白53でゲート未達。35° A/Bも17/18完筆、端点非改善だった。

## 最小実装

1. `BrushConfig`に任意の固定接触角を一つだけ追加し、まず3画以下の単純字の露出横画にだけ適用する。
2. `tilt_prepare`で物理45°へ移動し、全pen-downでは傾斜サーボの関節角だけを固定する。アーム姿勢による紙面上の実角度変化は許し、接地後のIKは筆先XYZだけを解く。
3. 接地中の方策第6出力は無効にし、通常は傾斜サーボを固定する。筆先XYZが160周期以上止まった場合だけ位置回復の余剰自由度として第6軸を解放する。角度演出には使わず、6次元I/O自体も変えない。
4. 接地前は45°姿勢を作り、接地後はXYZだけを主タスクにする。位置誤差を姿勢誤差で減衰させない。
5. 筆圧は既存の実測ループを使い、起筆・送筆・収筆それぞれの連続目標圧へZで追従する。強制滞留や墨跡縮小は追加しない。
6. 採択済み較正は85 mmの有効荷重1.20 N、110 mmは0.80 N、圧補正上限4.5 mm。

## 検証順序

1. `一三十`×6配置で固定45°を現行動的・直立と比較する。
2. 完筆18/18、衝突0を必須とし、beauty、端点、圧、幅、布白が現行を上回る場合だけ全60ケースへ進む。
3. 全60ケースで完筆100%、衝突0、圧誤差中央値0.08以下・p90 0.18以下、幅比0.90–1.10、消失布白14以下を確認する。
4. 固定45°が未達なら角度掃引は増やさず、Zの起筆／送筆／収筆プロファイルだけを直す。
5. 物理ゲート通過時だけWindows CUDAランを起動する。未達時はCUDAへ不良expertを渡さない。
