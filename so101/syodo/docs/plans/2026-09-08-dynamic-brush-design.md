# 実機軌道を穂先の接触シミュレーションで評価する

ユーザーの「習字は筆先の動きが大事」という要望に対応する。位置指令だけのFK検証を、穂の曲がり・摩擦・筆離れ・書き跡の評価へ広げる。

## 確認した欠陥

旧deskは把持位置から毛先までの12 cmを`brush_tuft_cm`へ入れ、「穂そのものが12 cm」と誤記していた。現物は把持位置→穂元の剛体軸80 mmと、穂元→毛先の毛40 mmである。旧シミュレーションはIK用の無変形毛先だけを120 mm先へ置き、38 mmの弾性穂を把持位置から生やしていたため、剛体軸と穂元が欠落していた。全長120 mmを保ったまま穂元を80 mm先へ移し、変形・接触する3節は40 mmだけにする。断面半径・密度・弾性係数の実測はないので、この幾何修正を物性較正として扱わない。

## 方針

既存MuJoCoの3節・6曲げ自由度を使い、保存済み実機指令を時間補間して再生する。腕の指令追従を理想化した場合の穂そのものの挙動をまず分離する。穂の状態は接触と空中を通して保持し、各点で曲げをリセットしない。紙との接触力から墨を置き、pen_downフラグだけでは墨を置かない。先端の向きとたわみを筆跡へ渡す。

出力は穂先・無変形穂先・接触点・たわみ・曲げ・接触力のCSV、時系列NPZ、予測筆跡PNG、JSON診断。文字と基本運筆で、弾性と摩擦を変えた感度も比較する。`hw-write`は本書き前にnominal再生だけを実行し、時間のかかる感度比較とGIFは明示したときだけ行う。

毛束ごとの大規模シミュレーションは多数の未実測パラメータを増やす。簡易な遅れモデルだけを別設計すると既存の接触物理との不整合が残る。そのため既存弾性モデルの修復と時間再生を先に行う。

## 合格と限界

無変形時に動的穂先とIK毛先が一致すること、剛体80 mm＋穂40 mm＝全長120 mmであること、同じ腕姿勢でも直前の進行方向によって毛先位置が変わること、高さ15 mm以上の空中移動で接触・墨がないこと、時間刻み1.0 msと0.5 msの終端位置が0.2 mm以内であることを検証する。

現行の8/−12 mmは実機接地との整合が未検証。シミュレーションの接触不足を良く見せるため紙や軌道を動かさない。硬さ・摩擦・圧力幅関係は未較正と明示し、結果を実機合格やcanonicalモデル更新に使わない。USB未接続なので実機動作は行わない。

参考: [Wang et al., dynamic brush model](https://arxiv.org/html/2003.01565v1) は接触足跡のずれ・向き・変形の履歴と実測による同定を扱う。[MuJoCo modeling](https://mujoco.readthedocs.io/en/stable/modeling.html) は形状からの慣性推定と接触パラメータの仕組みを説明する。本実装は同論文の再実装ではなく、既存の節構造を使う。
