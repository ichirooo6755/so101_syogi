# 全長12 cm・筆軸8 cm・穂4 cmの実機書字を改善する

2026-09-08。open issue対応に続く「実機でうまく書けるように」という依頼を優先する。

## 原因と変更

現行deskと作業中のコードで「文字・学習・菅原」を再生成すると、IK後に深さ補正を関節へ外挿し、関節端で丸めた最終指令に最大17〜23 mmの毛先誤差が生じる。生成時に表示していた誤差はその補正前だった。画間の空中移動にも手前の補正が入り、60 mmの高さが約40 mmまで下がる。

1. 奥+8 mm、手前−12 mmの設定を毛先の目標座標へ先に反映する。接触では全量、上げ下げでは徐々に減らし、画間の60 mm面では補正をゼロにする。
2. 前の姿勢から連続するIKを解き、最終指令で位置・筆傾き・関節端余裕・隣接点の変化を検証する。失敗を関節の丸めで隠さない。
3. 保存したNPZを独立にFK検証してから本書きへ進む。`--prepare-only` で接続せず同じ経路を検証できる。
4. 古いtraceと筆圧設定変更前のtraceを拒否する。開ループでは検証後の深さ再補正を廃止する。
5. 実機の位置を読み戻し、直前の指令との差をCSVへ記録する。中断までの記録を保持する。

## 検証の境界

位置誤差1 mm以内、筆傾き8°以内、隣接点5°以内、関節端2°以上、画間60 mmを維持する。現行deskで3語と1文字を検証し、回帰テストを実行する。全常用漢字や未知の机で到達可能とは主張しない。

これらは指令の幾何学的検証であり、動的追従・筆圧・たわみ・紙上の字形の合格ではない。現在USB未接続のため、本書きは実行しない。再接続後は既存の較正照合を通し、紙上の線と位置・荷重記録を照合する。旧「12 cm穂」PPOは起動せず、既存canonicalモデルも変更しない。
