# 実機アタッチメント準拠の筆傾斜回復設計

## 目的

グリッパー用サーボを筆の傾斜自由度として使い、起筆傾斜を有効にしたまま
常用漢字 2,136 字で beauty 85 以上・完筆 100% を回復する。

## 承認済みの機構解釈

`cad/brush-tilt/assembly_reference.step` と Fusion の確定寸法を正とする。

- サーボ回転軸: `Wrist_Roll_Follower` 座標系の Y 軸
- ピボット位置: `(20.077, 0, 24.350) mm`
- 筆軸: サーボ軸と直角
- 筆中心線: ピボットから X 方向へ `7.764571 mm` オフセット
- 穂先: ピボット基準で `(7.764571, 0, -28.977775) mm`
- ピボットから穂先: `30.000 mm`
- 穂の根元: `(7.764571, 0, 9.022225) mm`
- 穂の長さ: `38.000 mm`、筆全長: `56.000 mm`
- 45 度傾斜時の穂先移動: `22.961 mm`
- サーボ直立ホーム: 電気角 `45°`（有効傾斜 `-55°..+55°`）
- 実機配置: 台座 `35 mm`、紙中心 x=`305 mm`、紙余白 `75 mm`

現行 MJCF のように筆を回転軸上へ移動してはならない。既存の分節穂モデルは
ローカル +X 方向のまま再利用し、その親ボディを Y 軸まわりに 90 度回して
実機の -Z 方向へ向ける。これにより曲げ物理と IK の筆軸定義を増築せずに保つ。

## 実装順序とゲート

1. MJCF に上記のピボット、オフセット、直交する筆軸を反映する。
2. 幾何テストで 30 mm、直角、45 度時 22.961 mm を固定する。
3. 既存 DLS IK を実物幾何で再評価し、必要な最小修正だけを加える。
4. PPO を使わない expert action で代表字と既存失敗字が完筆することを先に確認する。
5. beauty 85.224 の `kaisho-yohitsu-shapefit-cont/final_model.zip` を親にして
   Windows CUDA 適応学習を行う。完筆ゲートを通らない状態では学習を始めない。
6. 128 字で完筆 100% と beauty 非退行を確認後、2,136 字を評価する。

既存 run、モデル、dirty worktree、採択済み sansetsu は上書きしない。
