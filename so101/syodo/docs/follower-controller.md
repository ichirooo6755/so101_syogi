# Xbox コントローラーで Follower を操作

`Followerコントローラー.command` を起動します。現在の USB ポート `/dev/cu.usbmodem5B7B0140931` に接続し、モーター 6 個の `syodo_follower` 較正・エラー・位置制御モードを確認します。接続時にはトルクを変更しません。Xbox のボタンを一度押してブラウザーに認識させ、「Follower に接続」を押します。腕を支え、周囲を空け、スティック、LT・RT、十字キーと A・B を離して「操作開始」を押します。

操作開始後、左スティックは肩、LT・RT はひじ（ID3）、十字キー上下は手首の曲げ（ID4）、十字キー左右は手首の回転（ID5）、A/B はグリッパーを操作します。左右反転モードは肩の回転と手首の回転の入力方向を反転します。停止中に切り替えてください。ID5 は教示した安全範囲を保存するまでは接続時の姿勢を中心に ±15° に制限します。再接続すると中心は更新されます。A/B の開閉方向と各関節の方向は実機で少しずつ確認してください。

ID6 が過負荷の場合はグリッパーを操作対象から除外します。操作中に検出した場合は一度停止して他の関節を保持し、把持物と周囲を確認後に「操作開始」で残りの関節を再開できます。グリッパーの保持は保証できず、把持物が落ちる可能性があります。ID6 の過負荷を解消してから再接続するとグリッパーを再び操作できます。バイラテラルは両腕の全関節に異常がない場合だけ使用できます。

較正範囲の外の関節にはトルクを入れず、GUI に表示します。それ以外の関節だけを操作できます。トルクを入れない関節は自重で動く場合があるので、腕を支えてください。スティックを戻すと位置を保持し、通信途絶・コントローラー切断では操作を解除します。ウィンドウのフォーカスが外れたことだけでは停止しませんが、ブラウザーが入力の取得や通信を止めた場合は停止します。停止・切断時も保持する設計ですが、電源断や通信障害時の保持は保証できません。物理的な非常停止手段を用意し、初回は空中で確認してください。

モーター通信は Feetech の Python SDK を使い、LeRobot に保存された Follower 較正と実機の値を照合します。書道動作や軌跡再生は行いません。

「停止・保持」は位置を保持し、「トルク OFF」は確認後に全関節を脱力します。どちらの場合も腕を支えてください。「較正範囲を記録」はトルクを OFF にして手で動かした関節の範囲を記録し、確認後に「較正を保存」で反映します。ID5 も対象です。ケーブルをねじらずに教示してください。Follower は回転位置の 0 と 4095 をまたがないようにします。Leader ID5 の例外は下記のとおりです。不連続な位置変化を検出すると記録を中止します。トルク OFF のまま中止できます。保存するとサーボの制限と LeRobot の較正が更新され、元のファイルはバックアップされます。

Leader の範囲は「Leader を較正用に接続」を押して対象を切り替えてから、同じ記録→確認→保存の順に教示します。Leader の保存済み較正とサーボの値が一致し、全モーターが応答する場合に使えます。全回転設定の Leader ID5 が 4095 と 0 の境界を通っても記録は続き、ID5 は元の 0〜4095 設定を維持します。境界をまたぐ狭い範囲への再設定ではありません。ケーブルをねじらず 1 回転以内で教示してください。この画面は既存の原点オフセットを維持する範囲の再教示で、初回の原点設定や未応答のサーボを修復する機能ではありません。Leader の較正変更後は教示姿勢やバイラテラルを再確認してください。

速度スライダーは本体の角速度指令の上限と追従幅を調整します。サーボのトルク上限・電流制限は変更しません。実際の速度と負荷に対する動きは実機で確認してください。

## バイラテラル

Leader と Follower を USB と電源に接続し、両腕の周囲を空けて支えます。「両腕を接続」でそれぞれの保存済み較正、モータ状態、動作モード、現在位置を確認し、「バイラテラル開始」で現在姿勢の差を維持した双方向の位置追従を開始します。姿勢合わせの自動移動はありません。Xbox の接続は不要です。ID5 は両腕とも開始位置から ±15° に制限します。位置差が大きすぎる場合や通信が途切れた場合は停止を試みます。「停止・保持」「トルク OFF」「切断」は両腕に作用します。Leader のトルク上限はバイラテラル開始時に一時的に下げ、「トルク OFF」で両腕の脱力を確認した後に復元します。保持したまま切断すると下げた上限はそのまま残ります。

このモードは位置の双方向追従で、接触力や筆圧を測定するものではありません。障害物のない空中で低速の短い動作から確認し、動作を人が評価するまで筆記や接触に使わないでください。通信障害や電源断時は保持を保証できません。
