# SO101 書道 v4：筆圧の横偏心をなくした交換部品

筆軸をロードセルの幅中央の面へ移し、軸方向筆圧によるねじりを減らした版です。
本体「部品１」とロードセルの向き・位置は今回変更していません。開始時点の本体の追加加工、サーボ、手首部品の配置も維持しています。
以前のキャリアとカートリッジは削除せず非表示で残し、現在は次の2部品に置き換えています。

- `Brush_Load_Carrier_Centered:1`
- `Brush_Cartridge_Centered_15mm:1`

## 変更点

| 項目 | 以前 | v4 |
| --- | ---: | ---: |
| 筆軸X（Fusion組立座標） | 50 mm | 30 mm |
| ロードセル中央X | 30 mm | 30 mm（変更なし） |
| 横方向の公称偏心 | 20 mm | 0 mm |
| 軸方向5 Nによる長手軸まわりの追加ねじり | 100 Nmm | 公称0 Nmm |
| カートリッジのフランジ下面Z | 8.5 mm | -26.5 mm |
| 筆軸Y | 2.762946202 mm | 変更なし |

柄とセルをぶつけないため、保持部を下へ移し、左右対称の2枚の縦壁でセルの自由端へつなぎました。
以前のキャリアの自由端側の上面・側面形状は切り出しコピーで残しています。
筆の上端はカートリッジ内部Z=7.5 mmの止め面で受け、厚さ2 mmの上端キャップが荷重を伝えます。
これにより筆をセンサや固定側へ直接突き当てる経路を作りません。
筆を締め付けるクランプや割り溝はありません。ホットグルーは筆とカートリッジの間だけに使います。

横力、姿勢に伴う自重、加速、動的なねじりがすべてなくなるという意味ではありません。ロードセルの電気出力の精度は実機で校正・確認が必要です。

## 印刷ファイル

| ファイル | 内容 | STLの外形 X×Y×Z |
| --- | --- | --- |
| `01_centered_load_carrier.stl` | 中心合わせキャリア、M3ナットポケット2個 | 32×52×53 mm |
| `02_centered_brush_cartridge_15mm.stl` | 上端ストッパー付き筆カートリッジ | 約30×52×36 mm |

STLはmm単位、各部品の下面Z=0へ配置済みです。STEPは組立座標です。
それぞれの`_editable.f3d`は単独で編集できる部品データです。
`so101_centered_v4_linked_backup.f3d`は外部参照付きのアセンブリ控えで、通常の編集再開はFusionのクラウド設計「so101書道」を使用してください。
本体は変更していないため、今回の変更のために本体を再印刷する必要はありません。
旧キャリア、旧カートリッジ、非表示の旧別体上面カバーは、この版と同時に使用しません。

## ねじ・ナットと組み立て

金属M3ねじを使い、木ねじ・タッピングねじは使いません。

| 箇所 | 使用部品 |
| --- | --- |
| キャリアからロードセル自由端 | M3×8 六角穴付き2本。樹脂側φ3.4通し穴、φ6.2×深さ3.2 mm座ぐり |
| カートリッジのフランジからキャリア | M3×10 六角穴付き2本＋通常のM3六角ナット2個 |
| 本体からロードセル固定端 | 既存のM3×12の2本を継続使用。今回変更なし |

ナットポケットは対辺5.8 mm、深さ2.6 mmで残しています。樹脂のM3雌ねじには置き換えていません。
自由端ねじの公称ねじ込みは5.2 mmです。実物のセルで底付き・突出がないことを確認してください。

1. 筆カートリッジを付ける前に、キャリアをセル自由端へ固定します。ねじと工具は下側のリング穴を通します。
2. セル固定端を本体へ設置します。中央変形部へ接触させず、固定端のみを固定します。
3. 筆をカートリッジへ下から入れ、上端の止め面へ当てます。ホットグルーを4か所の窓から入れて保持し、完全に冷やします。外面へのはみ出しは取り除きます。
4. M3ナットを横からリング上の空間へ入れ、六角ポケットへ落とし込みます。セルの上から真っすぐ落とす必要はありません。
5. カートリッジを下からリングへ差し込み、フランジをM3×10の2本で固定します。
6. 筆交換時はフランジの2本だけを外し、カートリッジを33 mm以上下へ抜きます。ロードセルのねじを外す必要はありません。

## 筆径とTCP

- `brush_dia`が筆径で、現在15 mmです。内側のグルー用穴は`brush_dia + 1 mm`、上下の案内穴は`brush_dia + 0.4 mm`です。
- 共通外径は22 mm、キャリア受け穴は22.6 mmです。12 mmと17 mmで再計算し、15 mmへ戻す試験を通過しました。
- 現在版の軸位置の記録は`centered_brush_axis_x`と`centered_brush_axis_y`です。旧版の位置パラメータ・非表示部品は履歴として残っています。
- カートリッジの基準位置は以前から **ΔX=-20、ΔY=0、ΔZ=-35 mm** です。これはFusionの組立座標であり、そのままロボットの世界座標へ加算する値ではありません。
- 筆先のTCPは、筆の長さ・挿入量・姿勢からあらためて測定してください。上記はカートリッジの位置差で、毛先の正確な変位を保証する値ではありません。

## 3Dプリントの初期条件

実物の造形はまだ行っていません。PETGまたはPLAで試作できます。

- 0.4 mmノズル、積層0.2 mm、外周6本程度を初期案とし、縦壁・接合部・ナット周辺を高密度にします。
- キャリアはSTLのリング下面を下にすると縦壁が立ちます。上側のブリッジ下面は支持が必要なので、サポートとブリッジのプレビューを必ず確認してください。
- カートリッジはフランジ下面が平らです。上端の閉じたキャップは約15 mmのブリッジを含むため、造形条件を確認してください。必要なサポートが内部へ残らず除去できる設定にします。
- 印刷後はリングへの差し込み、M3ねじ頭、ナットの着座、筆の止め面、カートリッジの着脱を単体で確認します。
- 樹脂を潰す締め付けや、中央変形部をまたぐグルー・張った配線は避けます。

## 確認範囲

- 本体・新キャリア・新カートリッジ・ロードセルのFusion標準体積干渉は0件。
- 現在表示されているサーボ部品・手首部品に、新2部品の体積干渉なし。
- 本体との最小隙間はキャリア約1.20 mm、カートリッジ約1.46 mm。
- センサ中央保護領域への侵入なし。φ15 mmの筆の挿入経路に干渉なし。
- カートリッジを下へ1/10/33/50 mm抜いた位置で干渉なし。
- キャリア自由端ねじはカートリッジを外した状態でアクセス可能。ナットは横からの挿入と着座を確認。
- 新部品のフィーチャ24個にエラーなし。STLは閉じたメッシュ、面向き一致。

物理的な造形、締結強度、疲労、校正、書字中の電気的な測定誤差は未確認です。
線形解析結果がある場合も、近似したセル形状、剛体本体、理想的なねじ・グルー接合の仮定下の参考結果であり、実物の強度・測定精度の証明ではありません。

## v4の参考荷重解析

Gmsh、scikit-fem、SciPyを用い、センサ・キャリア・カートリッジの3固体、79,064個の一次四面体要素で確認しました。
本体は剛体、センサ固定端は完全拘束、ねじ締結・グルーは理想固着、印刷部品E=1.5 GPa・アルミE=69 GPaの仮定です。
軸方向の荷重は筆の上端ストッパーへ与え、横力は筆軸上Z=-75 mmを仮定した等価力・モーメントとして与えています。

| ケース | センサ内部を通る合力 | 組立の最大変位（参考） |
| --- | ---: | ---: |
| 軸方向1 N | 1.0 N | 約0.0030 mm |
| 軸方向5 N | 5.0 N | 約0.0152 mm |
| X横方向0.5 N | 0.5 N | 約0.0961 mm |
| Y横方向0.5 N | 0.5 N | 約0.0480 mm |

軸方向5 Nのとき、セルの長手方向Y軸まわりのねじりは約2.3e-11 Nmmで、数値丸めの範囲です。
これはX方向の公称偏心を0にした幾何学的な結果と一致しています。通常の測定動作で必要なX軸まわりの曲げは残っています。

一方、同じ筆を同じ挿入条件で使うと保持部を35 mm下げた分だけ横力の腕の長さが増えます。
上記のX横力ケースではY軸まわりのモーメントは約51.25 Nmmです。**横力・摩擦によるねじりまでなくなる設計ではありません。**
旧版の解析は筆先Z=-40 mm、今回はZ=-75 mmの仮定であり、横力ケースの作用高さも異なります。
今回は1段階のメッシュによる参考解析で、変位の収束保証や実際のブリッジ出力の再現はしていません。

`analysis/fea_coarse.json`に結果を保存しています。再実行する場合は入力形状を同じにして、次を使用します。

```sh
.analysis-venv/bin/python scripts/load_path_fem.py --input-dir output/v4/analysis --level coarse --only-soft
```
