## M3ねじ

樹脂部品にはねじを直接切りません。ロードセル側のM3雌ねじ、または金属M3ナットへ締結します。

| 取り付け箇所 | 数量 | ねじ | 樹脂側の穴・受け |
| --- | --- | --- | --- |
| 本体からロードセル固定端 | 2本 | M3x12 六角穴付き | φ3.4通し、φ6.2 x 深さ3.2の座ぐり |
| キャリアからロードセル自由端 | 2本 | M3x8 六角穴付き | φ3.4通し、φ6.2 x 深さ3.2の座ぐり |
| スリーブのフランジからキャリア | 2本 | M3x10 六角穴付き | φ3.4通し、標準M3六角ナット2個を使用 |

ナット用の六角ポケットは対辺5.8 mm、深さ2.6 mmです。
M3六角穴付きねじは標準頭径5.5 mm、頭高さ3 mmのものを想定しています。
ロードセルの同じ端の穴間隔は7.4 mmです。
公称ねじ込み量は固定端・自由端とも5.2 mm。PDFには有効ねじ深さの指定がないため、実物で底付き・突出を確認してください。

## 補強内容と荷重経路

前回の固定台厚さ6 mmを10 mmへ変更し、座ぐり上の残り厚さを2.8 mmから6.8 mmに増やしました。
固定台の下へ連続した三角リブを追加しています。自由端キャリアにも三角リブを2本追加し、ねじ頭の挿入経路から外しています。

荷重経路は「筆 → ホットグルー → 交換スリーブ → フランジ → キャリア → ロードセル自由端 → 固定端 → 本体」です。
筆を締め付けるクランプ、コレット、割り溝、締め付けねじはありません。
フランジのM3ねじ2本はスリーブの脱落を防ぐためのものです。書道時の上向き荷重はフランジ上面とキャリア下面で受けます。
キャリアと本体の最小隙間はCAD上で約4.12 mmです。中央変形部へ固定構造をつなぐ接触経路は作っていません。
筆軸は、現在の本体の左右外側面の中央に配置しています。筆がアルミ製ロードセルを貫通しないよう前方へ逃がしています。

## 組み立て・着脱

1. 本体の固定台へロードセル固定端をM3x12の2本で取り付けます。
2. 自由端の下面へキャリアをM3x8の2本で取り付けます。中央変形部には接触させません。
3. スリーブへ筆を差し込み、先端位置を決めます。両端のφ15.4 mmガイドが筆を中央に保ちます。
4. 中央のφ16 mm穴とφ15 mm筆の間へ、4か所の窓からホットグルーを少量ずつ入れ、十分冷やします。外径に出たグルーは挿入前に取り除きます。
5. スリーブをキャリアへ下から差し込みます。キャリア上面の六角ポケットへM3ナットを置き、下からM3x10の2本で固定します。
6. 筆を外すときは、このM3x10の2本を外して筆とスリーブを下へ抜きます。ロードセルのねじを外す必要はありません。

本体とロードセルにホットグルーを付けないでください。グルーは筆とスリーブの間だけに使います。
構造をまたぐグルーや張った配線は荷重を迂回させ、測定に影響します。

## 筆径の変更

Fusionのユーザーパラメータ`brush_dia`が筆径で、現在15 mmです。
スリーブ内側のグルー用穴は`brush_dia + 1 mm`、両端ガイドは`brush_dia + 0.4 mm`で追従します。
交換インターフェースの外径は22 mmで共通、キャリア穴は22.6 mmです。
筆径12 mmと17 mmへの変更・再計算をCADで確認し、最後に15 mmへ戻しています。
径を変える場合はスリーブだけ書き出し直せます。標準外径22 mmでの設計範囲の目安は筆径8〜17 mmです。
17 mmを超える場合は肉厚も見直し、外径と受け側を一緒に変更してください。

## 造形の初期設定

実機造形はまだ行っていません。以下は試作開始用の設定です。

- PETGを第一候補とし、PLAでも寸法確認用の試作は可能です。
- 0.4 mmノズル、積層0.2 mm、外周6本、上下6層、インフィル40〜50%を出発点にします。
- ねじ・ナット周囲とリブ付け根は、スライサーの局所設定で高密度にします。
- スリーブはSTLの姿勢のまま、平らなフランジ下面を下にして造形します。窓の上辺は5 mmのブリッジです。
- 本体とキャリアは、張り出し下面へサポートを付け、造形プレビューで浮いた領域がないことを確認します。穴・座ぐり・ナットポケットへサポートを残さないようにします。
- 造形後は、M3ねじの通り、頭の収まり、ナットの収まり、スリーブの着脱を単体で確認します。締め過ぎて樹脂を潰さないようにします。

## 確認済みと未確認

- 3つの印刷部品とロードセルのFusion標準干渉検査: 0件。
- M3ねじ6本について、頭径5.6 mmの確認用形状を用いた挿入経路検査が通過。
- φ15 mmの筆の確認用形状と全構造の干渉なし。
- スリーブを下へ1、10、33 mm抜いた位置で干渉なし。
- 新規・変更対象の押し出し28フィーチャにエラーなし。
- STL3個は閉じたメッシュで、面の向きが一致。CAD体積との差は最大約0.06%。
- 保存したアセンブリと独立したスリーブ編集データを開き直して確認。

FEA、実物の造形・組み立て、破壊・疲労試験、ロードセル校正は未実施です。
本設計のCAD確認だけで耐荷重を保証するものではありません。
筆・スリーブを取り付けた状態でゼロ点を取り、既知の荷重で校正してから筆圧を使用してください。
