# SO-101 カメラ・HX711・ユニバーサル基板スタック V7

これは試作データです。現物での組立、印刷、爪の耐久性、通電、撮影、ロードセルの測定はまだ確認していません。必ず電源を切って組み立て、最初は無負荷・低速で干渉を確認してください。

## 印刷するもの

STL 6種類を各1個。01は取付本体、02は裏側の受け、03はカメラ台の抜け止めキー、04はXIAO台、05は2枚の基板のレール、06はレールの端の蓋です。STLはmm単位で、印刷向きに回転済みです。

- Bambu Lab A1 mini、0.4 mmノズル、PLAを想定。0.2 mm層、壁6周、25%インフィル、ブリム5 mm、有機ツリーサポートの条件でスライスを確認しています。印刷前にBambu Studioでサポート位置と小さな爪の出力を確認してください。
- ロボットへの取付はM3×12ねじ2本とM3六角ナット2個。ねじ頭直径5.5 mm以下・高さ3 mm以下を想定。基板固定に追加のねじ、ナット、接着剤は不要な設計です。
- 6部品に分かれていますが、積層方向と基板の取り外しを優先した構成です。爪やレールの実際のはまり具合はプリンタと材料により変わります。硬すぎる場合は無理に押し込まず調整してください。

## 配置と仮定

カメラ側から順に、XIAO ESP32S3 Sense → SparkFun SEN-13879 HX711 → ユニバーサル基板。HX711基板の外形はメーカー設計データより30.48 × 22.86 mm。ユニバーサル基板は同寸法に切り、両基板の厚さを1.6 mmとして設計しました。レール溝は約2.05 mmなので、現物の厚さによっては遊びが出ます。通電前にがたつきや抜けを確認してください。

XIAOの2列7ピン、2.54 mmピッチのヘッダ用に幅3.15 mmの2本の窓を設けました。基板裏からピン先端まで最大15 mmを仮定しています。実物のピン長、コネクタ、はんだの高さと曲がりを必ず確認してください。HX711前面の部品高さと、ユニバーサル基板表裏の部品・はんだ高さはそれぞれ最大3 mmの仮定です。配線の曲げ半径や突起は現物確認が必要です。

カメラの向きは既存の設定を維持し、USB-Cは前の側に近い向きです。実際のカメラ型式、撮影範囲、焦点、USBプラグの大きさは未確認です。配線は枠側面の窓から出し、ロボット全可動域で引っ張られないようにしてください。

## 組立順

1. 01と02で選択セット2の位置を挟み、M3×12ねじ2本とナット2個で取り付ける。サーボの内側取付形状や既存の筆取付部は変更しない。
2. 腕の外で、04に05を差し込み、XIAOとそのヘッダ、HX711、切ったユニバーサル基板をそれぞれレールに差し込む。ピンや電子部品に力をかけない。
3. 06の爪を軽く外側にたわませて端に取り付ける。爪の破損に注意する。
4. 完成した基板スタックを01の受けに差し込み、03の抜け止めキーを横から差し込む。取り外すときは小穴から細い工具で爪を押し、無理に引かない。
5. 電源を入れる前にレール、隙間、はんだ、配線、USBプラグ、手首と腕の全可動域を実物で確認する。現物寸法に合わない場合は設計を調整する。

## 配線の基本

SparkFun HX711はアナログ電源VCCとデジタル電源VDDが別です。メーカーの3.3 Vロジック向け例は VCC=5 V、VDD=3.3 V、GND共通。DATとCLKはそれぞれXIAOの3.3 V GPIO（例えばD0、D1）へ接続します。VCCとVDDの短絡や5 VがGPIOへ入らないことを確認してください。この接続では以前のTXS0108Eレベル変換器は不要です。ロードセル4線は色だけを信用せず、そのロードセルの資料で励起±・信号±を確認してください。

Wi-Fi送信やカメラのソフトウェア、ロードセルのゼロ点・既知荷重による校正は別途必要です。ノイズや筆先の実荷重の精度はこのモデルだけでは保証できません。
