## スライサーでの扱い

- 使用できる材料はPLAまたはPETGです。プリンタ／フィラメントに合った既存の設定を使用してください。
- STLは高精細設定・mm単位で出力しました。STL自体には単位情報がないため、読込時は必ずmmとして扱ってください。
- 各部品を平行移動し、外接範囲の最小XYZを原点に近づけています。形状や大きさの変更、穴の拡大、部品の回転はしていません。
- 初期姿勢はアセンブリ由来で、最適な造形方向を確定したものではありません。スライサーで接地面・積層方向・サポートを確認してください。
- ロードセル差し込み部、M3の段付き穴、ナットポケット、筆穴に、取り除けないサポートを残さないようにしてください。
- 本体には元CAD由来の閉じた内部空洞が1個あります。外表面とは別のメッシュ面ですが、独立した2部品ではありません。空洞を自動で埋めたり、取り出せない内部サポートを生成したりしないよう、プレビューを確認してください。
- カートリッジの筆穴は上端ストッパー付きの非貫通穴です。上端が閉じているのは設計どおりです。
- 機種・材料・ノズルが未指定のため、G-codeや特定プリンタのスライス設定は含めていません。

## 組立前の重要事項

- サーボ取付部8か所の頭用穴は径5.4mmです。通常の頭径5.5mmのM3キャップねじは入りません。
  小頭M3×6・頭径4.5mm・高さ3mmを基準とし、同寸法なら元ねじを再利用できます。秋月／千石で適合する新品は未確認です。
  普通のM3×6を使うために、今回穴を拡大する変更はしていません。
- ロードセル固定側はM3×12を2本、可動側はM3×8を2本、カートリッジ固定はM3×10を2本＋M3六角ナット2個です。
- 木ねじ／タッピングねじで樹脂にねじを切る構成ではありません。
- ナットは対辺5.5mm・厚さ2.4mmを基準とします。実物寸法と印刷後の入りを確認してください。
- セルのねじ有効深さ、サーボのねじ深さ、印刷後の穴径・差し込み具合は実物で確認してください。過大な力で締め込まないでください。
- ホットグルーは筆とカートリッジの間だけに使用します。ロードセルのくびれや、固定側と可動側をまたぐ場所には付けないでください。
- 詳しい個数・組立順は同梱の `組立部品表.md` を参照してください。この部品表の解析状況などは2026-10-22時点の記録です。

## 後から筆径を変える場合

`source_cad/03_brush_cartridge_15mm_V5_editable.f3d` は元のパラメトリック形状です。
Fusionのユーザーパラメータ `brush_dia`（現在15mm）を変更し、再計算してからSTLを書き出してください。
STLを一括拡大縮小すると、キャリアとのはめ合いとねじ穴位置まで変わるため、その方法は使わないでください。
大きく径を変えたときは肉厚、グルー用窓、キャリアとの干渉を再確認してください。
今回、編集用ファイルを開いた使い捨てのコピーで12mm・17mmへ変更し、最後に15mmへ戻ることを確認しました。
外形とねじ取付位置は変えず、案内穴とグルー用穴が追従し、履歴のエラーが出ないことを検査しています。印刷用STLは15mmのままです。

## 同梱データと検証の範囲

- `source_cad/`: 編集用F3Dと、原点移動済みの参考STEP。F3Dは元のコンポーネント座標のままです。
- `preview/`: 各部品のFusionプレビュー。印刷方向の指示画像ではありません。
- `export_report.json`: Fusion元文書・版・体積・寸法・平行移動量と、元アセンブリが未変更であることの照合記録。
- `mesh_verification.json`: STLの閉じたエッジ、面の向き、寸法、CAD体積との比較。
- `cad_reopen_verification.json`: F3D／STEPをFusionで開き直した、ソリッド数・体積・寸法の検査。
- `cartridge_parameter_verification.json`: カートリッジの筆径パラメータをコピー上で変更して検査した記録。
- `cad_shell_audit.json`: 元CADのソリッド数と、外表面／閉じた内部空洞の区別。
- `package_verification.json`: STLの外表面・内部空洞とCADの対応、配置範囲、ファイル照合の記録。
- `SHA256SUMS.txt`: 同梱ファイルのハッシュ。

印刷に使用する形状はSTLです。編集にはF3Dを優先してください。
STEPは交換形式のため、手首のSTEPをFusionで再読込すると体積に約1.34mm³（約0.0061%）の差が生じました。
これは検査記録に実測値を残しています。印刷用STLや元F3Dに対して修復・形状変更を行ったものではありません。

このパッケージで検証したのは、書き出しデータの整合性とメッシュです。
実物の造形、層間強度、サポート除去、ねじ締結、校正後の筆圧精度を保証するものではありません。
初回は試作として組み付け・低荷重で確認してください。
