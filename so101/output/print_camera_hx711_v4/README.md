## 今回の構成

[SO101公式リポジトリの六角ナット式カメラマウント](https://github.com/TheRobotStudio/SO-ARM100/blob/main/Optional/SO101_Wrist_Cam_Hex-Nut_Mount_32x32_UVC_Module/README.md)
の「一体の台座を2本でロボットへ固定する」という構成を参考にした。
公式品は32×32 mmカメラ用で、カメラ側には別のM2ねじも使う。
このV4はXIAOとHX711向けに新規設計し、基板側もねじを使わず、金物の合計を2本＋2個にした。
公式STLをそのまま改変・流用した形状ではない。

選択セットAの長穴を本体と裏押さえで挟む。選択セット2の外側方向へ短く張り出す配置は維持。
V3の箱形支持、ねじ止めカバー4点、基板用ねじ/ナット4組は廃止。
浅い位置決め受けへ基板を載せ、以前許可されたホットグルーを端だけに使って保持する。
ホットグルーなしで基板を確実に保持する設計ではない。

元の部品１・Wrist・サーボ取付面・ロードセル・キャリア・筆カートリッジは変更していない。
追加台座は部品１と一緒に回転し、ロードセルの自由端やくびれには触れない。
V1～V3は履歴として残している。この版へ旧版のカバーや台座を混ぜないこと。

## 印刷物と金物

| 印刷するSTL | 個数 |
| --- | ---: |
| 01_simple_camera_HX711_bracket_V4.stl：一体台座 | 1 |
| 02_A_slot_backing_V4.stl：長穴の裏押さえ | 1 |

| 追加台座に使う金物 | 個数 |
| --- | ---: |
| M3 × 10 mmねじ | 2本 |
| M3六角ナット | 2個 |
| ホットグルー | 基板の端を止める少量 |

M3並目ピッチ0.5 mm、ねじ頭径5.5 mm以下・頭高さ3 mm以下、ナット対辺5.5 mm・厚さ2.4 mmを想定。
ねじ長さは頭下面から先端まで。M3 × 8やM3 × 12を今回の2本と置き換えない。
樹脂へ木ねじでねじ込む構成ではなく、金属ナットで締結する。
既存ロードセルねじと小頭サーボねじはそのまま使い、追加台座用へ流用しない。

## 印刷

PLA/PETG、単位mm、倍率100%。STLは造形姿勢に回転済み。

- 01：Aと接する平面がベッド。基板受けと斜めのカメラ受けの下面へ取り外せるサポートを付ける。
  箱形の閉じた空洞は作っていないが、穴や隙間へ除去不能なサポートを入れない。
- 02：平らな背面がベッド、ナット通路のある突起が上向き。
- 0.4 mmノズル、積層0.16～0.20 mm、外周4本は未検証の試作開始値。温度は材料の指定に従う。
- 全体の拡大縮小で穴合わせをしない。まず01/02の長穴への差し込みと保持を現物で確認する。

## 組立

1. 電源を切り、サポートとバリを除去する。02の背面からM3ナット2個を入れる。
2. 裏側の小さいTXS0108E基板は、ロボットへ取り付ける前に受けへ載せる。
   PCBの角付近と樹脂の間を少量のホットグルーで止める。裏のはんだ用に公称2 mmの隙間を設けた。
3. 02をAの長穴へ内側から差し込み、外側へ01を当てる。
   基板受けの下部の直径6.2 mm開口からM3 × 10のねじ頭ごと入れ、2本を交互に手締めする。
   6.2 mm穴は頭/工具を通すためのもの。奥の固定座面の軸穴は3.4 mmで、そこでねじ頭が止まる。
4. 固定ねじを締め終えてからHX711を外側の浅い受けへ載せ、基板の角付近だけをホットグルーで止める。
   このねじを整備するときはHX711を外して工具の通路を空ける。基板越しに工具を押し込まない。
5. 下の斜め受けにXIAO ESP32S3 Senseを載せる。USBの開口を塞がず、端の少量のグルーで保持する。
6. レンズ、FPC、コネクタ、アンテナ、部品や放熱が必要な部分をグルーで覆わない。
   基板や樹脂を熱で傷めない量と作業方法にする。基板を取る際もFPCや部品を引っ張らない。
7. 配線は短く柔らかい線を使い、手首回転分の余裕を残す。セルの自由端を線で突っ張らせない。
   セルのゲージやくびれにはグルーを付けない。既存の筆の保持方法は変更しない。
8. グルー冷却後にガタ・剥がれ・配線張力・干渉を手で確認し、低速・低負荷から試す。
   最後に筆圧をゼロ調整・校正する。滑り、白化、割れ、グルーの剥がれがあれば運転しない。

HX711は1枚。裏側の基板はTXS0108Eの電圧変換基板1枚で、HX711の2枚目ではない。
XIAO、HX711、変換基板の電圧と配線は「配線と電子部品.md」を参照。

## 検査と限界

- 新規2部品、既存SO101、メーカーXIAO実装CAD、基板包絡、M3金物の静止体積干渉なし。
- 部品１と追加台座を一緒に5度刻み73姿勢で回し、サーボ/手首への追加体積干渉なし。
- 締付けで片側0.25 mmの隙間が閉じた位置、ねじ頭を含む挿入、基板の接近、カートリッジ着脱をサンプル確認。
- 各ねじは公称10 mm、厚さ2.4 mmのナット全厚に掛かり、軸が通って頭が座面で止まることをCAD確認。
- STL2点の閉じたメッシュ・寸法・体積、個別F3D/STEP各2点と全体F3Dの開き直しを確認。
- これは荷重解析ではない。積層強度、クリープ、保持摩擦、ホットグルーの耐久性・耐熱性は未検証。
- 実印刷、実物基板のはんだ/配線、上流アーム/ケーブル、撮像・ピント、電気動作・筆圧ノイズは未検証。
  XIAOは2023年CADを参照。届いた現物と照合してから接着する。

`source_cad/`のF3Dは組立座標、STEP/STLは造形座標。
名前付きベースフィーチャのソリッドで編集できるが、寸法パラメータ連動モデルではない。
Fusionの別ドキュメント名は`so101_SelectionA_Simple_Camera_HX711_V4`。
構築コードはプロジェクトの`scripts/build_simple_camera_v4.py`。
`preview/`に配置画像、`checks/`に数値検査結果がある。
