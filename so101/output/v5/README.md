# SO101 書道 V5：可動域優先のヨークと対称カートリッジ

前案の長いキャリアは、現在の手首ケースに片方向5°で干渉しました。
V5では工具を前へ移し、部品１を外側レール＋上側連結の一体ヨークへ作り替えています。
旧部品は削除せず非表示で保持しています。追加されたユーザー編集は上書きしません。

新ヨークのホーン穴は半径7 mmの十字配置で、現在のサーボホーンの穴位置に合わせています。

## 対称性と荷重経路

カートリッジは、筆軸を通るX・Yの両方の鉛直面に対して鏡面対称です。
フランジの二つの耳、上下の案内、止め面、四方向のグルー窓を対称にしています。
CADの鏡像との差体積は数値丸めの範囲でした。キャリアはセル幅方向Xに鏡面対称です。

筆の上端 → 厚さ2 mmのストッパー → カートリッジのフランジ → キャリアの両壁 → セル自由端 → セル中央変形部 → 固定端 → ヨーク、という経路です。
筆の上端は組立Z=30.5 mm、キャップ上面は32.5 mm、キャリア上側プレート下面は33.5 mmです。
両者の公称隙間は1 mmで、筆を固定側やセルへ直接突き当てない構造です。

対称化で、軸方向筆圧に伴う幅方向の偏心ねじりは公称0になります。
ただし、筆先の横力、筆軸周りのねじり、ホットグルーの塗布差、姿勢による自重、加速度、配線張力は残ります。
単一出力のセルから独立した筆圧とねじりを完全に分離できるという意味ではありません。

## 確認した可動範囲

Fusionの一時BRepで、工具一式をサーボのY軸まわりに回転し、固定側のサーボ・手首ケースとの体積干渉を確認しました。
初回のV5形状では、−180°〜180°を2°刻み、181姿勢で干渉なしです。
直径15 mm、長さ82.5 mmの仮の筆柄も含めています。
これは実機の回転可能角度の保証ではありません。上流アーム、配線、サーボの角度制限、印刷誤差、荷重による変形は別途確認が必要です。
手首の追加編集後の最終確認は、別途記録します。

## 締結と組立

木ねじ・タッピングねじは使いません。樹脂側は通し穴で、金属側のM3雌ねじ／金属ナットを使います。

| 箇所 | 設計上のねじ |
| --- | --- |
| セル固定端 | M3×12、2本。樹脂φ3.4、頭座ぐりφ6.2×3.2 mm |
| セル自由端 | M3×8、2本。樹脂φ3.4、頭座ぐりφ6.2×3.2 mm |
| カートリッジ | M3×10、2本＋通常のM3六角ナット2個 |
| サーボホーン負Y側 | M3×12、4本を想定。φ3.2通し、座ぐり底Y=-27 mm |
| サーボホーン正Y側 | M3×10、4本を想定。φ3.2通し、座ぐり底Y=28 mm |

セルねじの公称ねじ込みは5.2 mmです。必ず実物で底付き・突出がないか確認してください。
ホーンのモデル穴はφ2.5 mmです。M3タップ下穴相当ですが、実物のねじ規格・有効深さがM3であることを取り付け前に確認してください。
モデル上のホーン厚さから計算したねじ込み目安は負側2.05 mm、正側2.2 mmです。長すぎるねじでサーボ内部を傷めないでください。
ナットポケットは対辺5.8 mm、深さ2.6 mmのままです。

1. 手首ケース変更版と新しいヨークを組みます。ホーンの中心ねじは先に取り付け、両側フランジの4本ずつで固定します。
2. セル自由端にキャリアを付ける前に、セル固定端を負Y側からソケットへ差し込みます。厚さ6 mmのセルに対して、設計スロットは6.4 mm、幅9.4 mmです。
3. 固定端を下からM3×12で固定します。一体の屋根は固定端の上側だけを覆い、中央変形部は覆いません。
4. キャリアを自由端へM3×8で取り付けます。ねじ頭へのアクセスにはカートリッジを外しておきます。
5. 筆を下からカートリッジの止め面まで入れ、四方向の窓からホットグルーを均等に入れます。別の接着剤、テープ、クランプは不要です。
6. グルーが冷えてから外面のはみ出しを取り除きます。キャリアとスリーブの隙間にグルーを付けないでください。
7. M3ナットをキャリアへ横から挿入して着座させ、カートリッジを下から入れてフランジの2本で固定します。
8. 筆交換ではフランジの2本を外してカートリッジごと下へ抜きます。筆単体を外す場合はカートリッジを取り外してからグルーを剥がしてください。

## プリントと校正

PETG/PLAを対象とした試作形状ですが、造形と強度の実機確認は未実施です。
初期案は外周6本、0.2 mm積層、レール・ナット周囲・接合部を高密度にします。
ヨークの丸い軸取付部とレール下面、キャリア上面のブリッジ、カートリッジの閉じたキャップ、手首ケース内部のサポートをスライサーで確認してください。
支持材を残したままセルを差し込まないでください。ねじ穴・スライド面は単体で確認し、樹脂を潰して合わせないでください。

筆径パラメータは`brush_dia`です。現在15 mm、グルー用穴は筆径+1 mm、上下案内穴は筆径+0.4 mmです。
12 mm/17 mmで再計算し、15 mmへ戻す検査を通過しています。共通スリーブ外径は22 mm、受け穴は22.6 mmです。
V5の軸位置は`v5_brush_axis_x`、長さは`v5_brush_sleeve_length`です。旧版パラメータも履歴として残っています。

長くした分、サーボへの荷重モーメント・自重・たわみが増えます。軸方向5 Nだけでも、80 mmの腕長によって手首には公称400 Nmmが加わります。
これはセルの偏心ねじりとは別の、ロボット関節が受ける通常のモーメントです。
筆先TCPは実物の長さ・挿入量・取付姿勢で再測定してください。組立座標差をそのまま世界座標へ加算しないでください。
取り付け後は無荷重ゼロ調整、複数の既知荷重、書字姿勢ごとの確認、横力・ねじりを加えた比較を低荷重で実施します。

## Fusionの静的応力解析

別のクラウド設計「so101_V5_筆圧検証_理想接触」に、ヨーク・セル・キャリア・カートリッジの4固体を用意しています。
樹脂はE=1.5 GPa、ν=0.35の仮定値、アルミはE=69 GPa、ν=0.33です。
樹脂の仮の降伏値20 MPa、アルミ55 MPaは表示用の仮定であり、実フィラメント／実セルの保証値ではありません。
解析結果と実施状況は、完了後に別途記録します。

Fusionの線形等方材解析は、FDMの積層方向・空隙・造形欠陥・クリープ・実際のグルーやボルトの滑りを再現しません。
また、セル内部の実際のひずみゲージ配置とブリッジ回路が不明なため、構造解析から「筆圧の電気出力が何％正確」とは判定できません。
参照: [Autodesk: 積層造形部品に対する解析の限界](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-reliable-are-the-Fusion-simulation-results-when-applied-to-additive-manufactured-materials.html)。
