## 初期版: SC616C固定部（旧版・履歴）

Fusionの既存「so101書道」を編集し、クラウドのバージョン14として保存済みです。
保存した設計を閉じて開き直し、配置と形状を再確認しています。

## 今回の変更

- 既存の「部品１」に、SC616Cの固定端を支える厚さ6 mmの台座を一体化。
- ロードセルの回転姿勢は変更せず、元の配置からX方向+5.5 mm、Y方向-0.537054 mmだけ移動。
- 固定端のM3ねじ2か所に対し、台座に直径3.4 mmの通し穴を7.4 mm間隔で作成。
- 底面に直径6.2 mm、深さ3.2 mmのねじ頭用座ぐりを作成。
- 中央の変形部と自由端を本体から離し、荷重を迂回して本体へ伝える接触を避ける構成。
- 将来の筆軸は既存ヨークの左右中央面に配置できるよう、自由端の穴2個の中点を合わせています。
- `brush_dia`は15 mm。今回の固定台形状には依存していません。次の筆ホルダー設計でこの値を参照します。
- 筆ホルダー、着脱機構、クランプは今回新規作成していません。

## 組み立て

固定側は、台座の底側からM3六角穴付きねじを2本挿入し、SC616Cの固定端に締結する構成です。
標準頭高さ3 mmのM3x8を想定すると、台座の残り厚さ2.8 mmに対して公称ねじ込み量は5.2 mmです。
図面はねじの有効深さを明記していないため、実物で貫通・底付きとねじの突出を確認してください。
反対側の2穴と中央変形部は固定せず、次の段階で自由端側へ筆ホルダーを取り付けます。

参照: フォルダ内の `SC616C-1kg load cell.pdf`。ねじ呼びは4-M3、同じ端の穴間隔7.4 +/- 0.1 mm、全長45 mm、厚さ6 mm。
幅には9.0 mmと9.3 mmの仕様があります。固定台はどちらの幅にも対応する幅で作成しています。
