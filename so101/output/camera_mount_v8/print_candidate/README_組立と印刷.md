# SO101 カメラ・HX711 基板スタック V8（ねじ固定試作）

V7の取付板にあった大きな開口をなくし、ねじ穴の周囲を連続した板にしました。カメラ台のキーと基板台の爪は廃止し、どちらもねじ・ナットで固定します。これは試作であり、実際の印刷、組立、強度、熱変形、振動、通電は未検証です。

## 必要なもの

STLは各1個、合計5個。STLの座標単位はmm、倍率100%です。

1. `01_bolted_mount_V8.stl` — 腕への取付本体
2. `02_slot_backing_V8.stl` — 長穴を挟む裏板
3. `03_XIAO_header_tray_V8.stl` — XIAOカメラ台、ヘッダ逃げあり
4. `04_HX711_perf_stack_V8.stl` — HX711とユニバーサル基板の台
5. `05_bolted_end_plate_V8.stl` — 基板台のねじ留め蓋

M3×12ねじ6本とM3六角ナット6個を使用します。内訳は腕へ2組、カメラ台へ2組、基板台の蓋へ2組です。ねじ頭は直径5.5 mm以下、高さ3 mm以下の想定です。ねじ穴は直径3.4 mm、ナット穴は対辺5.8 mmの設計です。実物と造形誤差で穴がきつい場合は軽く調整し、プラスチックや基板を割るほど締めないでください。

## A1 miniでの印刷

`SO101_A1mini_PLA_v8.3mf`はA1 mini、0.4 mmノズル、PLA用に5個を1プレートに配置した試作設定です。0.2 mm層、壁6周、25%インフィル、5 mmブリム、ビルドプレート上からの有機ツリーサポートでスライス済み。推定約22.6 g、約1時間28分ですが、材料や環境によって変わります。

印刷向きは、腕への取付板は平らな面を下、残りの基板台などはSTLに保存した向きです。必ずBambu Studioのプレビューでサポートが穴やナット挿入口を塞がず除去できること、壁と細い部分が出力されることを確認してください。サポートが必要な箇所があり、サポートなしの印刷は確認していません。層間の強度を含む実物の強さは、造形品質と材料の乾燥状態などに左右されます。

## 組立順

1. 基板スタックを腕の外で組みます。03に04を差し込み、XIAO、HX711、ユニバーサル基板をそれぞれレールに差し込む。ピンと部品に力をかけない。
2. 04の左右外側からM3ナットをそれぞれ1個差し込み、05の蓋をM3×12ねじ2本で留める。基板・はんだ・配線を蓋やねじで押さない。
3. 01と02で腕の選択セットAの長穴を挟み、M3×12ねじ2本・M3ナット2個で留める。既存サーボの内側取付形状は変更しない。
4. 完成した基板スタックを01のカメラ側座面へ差し込み、裏側のナット受け2か所へナットを入れ、カメラ台側からM3×12ねじ2本で固定する。ナットが座り、台の面がしっかり当たっていることを確認する。
5. 通電前に、ねじの突出、基板のがたつき、配線、USBプラグ、筆カートリッジ、ロボットの全可動域を現物で確認する。最初は低速・無負荷で確認し、接触や緩みがあれば使用を中止する。

## 寸法と電気上の注意

XIAO ESP32S3 Sense、SparkFun SEN-13879 HX711、HX711と同寸に切ったユニバーサル基板の順に重ねます。ユニバーサル基板は30.48 × 22.86 mm、両基板は厚さ1.6 mmを仮定しています。基板溝は約2.05 mmで、実物によっては遊びが出ます。XIAOは2列7ピン・2.54 mmピッチ、ピンの下向き突出は基板裏から最大15 mmを仮定。表裏の部品・はんだは最大3 mmを仮定しており、現物の高さや配線の曲がりは要確認です。

SparkFun HX711のメーカー例はアナログ電源VCC=5 V、デジタル電源VDD=3.3 V、共通GNDです。DATとCLKはXIAOの3.3 V GPIOへ。VCCとVDDやGPIOが5 Vに短絡していないことを確認してください。この構成ではTXS0108Eは不要です。ロードセル線の極性は実物の仕様で確認してください。

基板の実物嵌合、カメラの撮影範囲、ロードセル校正、Wi-Fi/USB通信や強度試験は行っていません。CAD上の干渉検査は実機の全てのケーブルや連続可動域の検証ではありません。
