# 球面の薄膜シミュレーター

球面上の渦度・膜厚・界面活性剤を計算し、正距円筒図法のテクスチャを連番出力する試作です。作者が公開した説明と動画を調べ、色・渦の規模・動きの速さを比較して調整しました。**作者の元プログラム、初期条件、数値計算法は公開情報から特定できておらず、完全再現ではありません。**

## 作者の説明から分かったこと

- 作者は、球面の薄膜の渦を出力する専用の独立プログラムと説明しています。膜厚・色の8K正距円筒画像のほか、Velocity、Thickness、Direction のパスにも言及しています。 [制作方法の返信](https://x.com/yeah_tuna/status/2117871859089998057) / [専用プログラムの返信](https://x.com/yeah_tuna/status/2117873494847623652) / [出力パスの返信](https://x.com/yeah_tuna/status/2117434714692977042)
- 重要な訂正として、作者は参照論文について、メッシュベースで自分の方法とは異なると述べています。論文の粒子・メッシュ法が元プログラムに採用されているとは断定できません。 [作者の説明](https://x.com/yeah_tuna/status/2117244487483494741)
- 作者の別の球面レンダリング例では、テクスチャの生成と Cinema 4D／Octane によるレンダリングを区別しています。これは別投稿の制作方法です。 [関連投稿](https://x.com/yeah_tuna/status/2117246019889250416)

## 実行

[起動.command](起動.command)をダブルクリックし、ブラウザで「計算して保存」を押します。初期設定は新しい「球面格子」方式、小さな渦の割合 1、初期の細かな膜厚差 120 nm、渦の強さ 20、界面活性剤の力 0、流体格子 1024×512、準備 30 ステップ、24 フレーム、出力画像 1024×512 です。処理が終わったフレームからプレビューされ、出力先は `output/grid_日時/` に表示されます。

以前の「粒子・メッシュ」方式も計算方式の選択肢に残しています。両者とも独自の近似で、どちらも作者のソースコードではありません。終了するには起動したターミナルで Control-C を押してください。停止ボタンは、進行中の時間ステップまたはフレームの書き出しが終わると反映されます。

「開始前の計算回数」は画像の先頭を保存する前の準備です。「フレーム間の計算回数」と「フレームの時間倍率」は保存画像の間のシミュレーション時間を決めます。時間刻みの初期値 0.02、回数 1、倍率 0.22 なら、フレームごとの時間差は 0.0044 です。連番自体には再生フレームレートは埋め込まれません。

「流体画像の幅」は計算解像度、「保存する画像幅」は書き出し解像度です。**8192×4096への保存は流体計算が8Kで行われることを意味しません。** 計算の細部は流体画像の幅で制限されます。幅を上げるとメモリ・計算時間が増えます。

## ファイル形式

- `color_NNNN.png`：近似薄膜干渉色の8-bit RGB。露出と彩度の調整を適用。
- `thickness_nm_NNNN.png`：整数nmの16-bitグレースケール（0〜65535 nmに制限）。
- `velocity_NNNN.png`：接線速度のワールド XYZ を8-bit RGBに格納。`(RGB/255*2-1)*速度画像の最大値` で復号。範囲外は切り詰められるため、`metadata` の `velocity_clipped_component_fraction` を確認してください。
- `direction_NNNN.png`：正規化した速度のXYZを8-bit RGBに格納。`RGB/255*2-1` で復号。速度ゼロ付近の方向には意味がありません。
- `state_NNNN.npz`：球面格子上の浮動小数点の膜厚、界面活性剤、渦度、XYZ速度、時刻。再開ボタンは未実装です。
- `metadata_NNNN.json` と `settings.json`：フレームごとの時刻・符号化や、準備／フレーム間の時間刻みなどの設定。

画像は上が北極、中央が経度0、左右端が経度±π、ピクセル中心をサンプリングしています。Color以外のPNGは数値データとして扱い、色変換しないでください。速度方向はワールドXYZであり、UV接線座標ではありません。

## 新しい球面格子方式の内容と限界

球面の緯度経度格子上で渦度を保持し、球面ポアソン方程式を経度方向のフーリエ変換と緯度方向の有限体積法で解いて速度を求めます。渦度・膜厚・界面活性剤は球面上を半ラグランジュ法で移流します。初期の渦と膜厚の小さな変化は一度だけ与え、アニメーション中は速度に従って運びます。小さな渦の割合を上げると、初期渦から大きな空間スケールの成分を2回抑えます。「初期の細かな膜厚差」は初期渦度に関連づけた膜厚変化の大きさで、元動画に近づけるために選んだ初期条件です。元作者の初期状態を測定したものではありません。継ぎ目は周期接続、極では経度を半周ずらして接続します。

接線方向の重力排液は指定速度、界面活性剤による効果は濃度と膜厚の勾配から生じる渦度の近似として扱っています。膜厚の輸送後は全体量を補正するため、局所的な保存を保証しません。論文の膨張成分を含む完全な運動方程式、法線方向の変形・表面張力、粘性の物理モデル、蒸発と破裂は未実装です。異常な膜厚では計算を停止します。時間と速度は無次元で、入力値は実測物性値ではありません。

色は一定屈折率・法線入射・等エネルギー白色光での干渉を波長ごとに近似積分し、露出・彩度を調整します。[Wyman ほかのCIE等色関数近似](https://jcgt.org/published/0002/02/01/)を使用。視角、照明環境、実測光学特性、Octaneのレンダリング設定は再現していません。

`OPENBLAS_NUM_THREADS=1 .venv/bin/python verify_grid.py` で、球面上の既知の関数を使ったポアソン方程式、静止場、継ぎ目・極、短時間の全体量補正を検査できます。画像サイズとGUIの実行・停止も確認しました。時間・解像度の収束、長時間の安定性、元プログラムとの数値・映像一致は未検証です。
